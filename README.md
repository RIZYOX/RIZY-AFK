# RIZY AFK

Bots AFK Minecraft (Java et Bedrock) : site https://afk.rizyox.fr

## Télécharger l'application

Prends le dernier `RIZY-AFK-Setup-x.y.z.exe` dans [Releases](https://github.com/RIZYOX/RIZY-AFK/releases/latest).

Il te faut un code d'accès `RIZYAPP-…` pour l'activer. L'application se met à jour toute seule.

Documentation : https://afk.rizyox.fr/docs
